# For AI agents

1. Read `CLAUDE.md` first for the project's rules and commands.
2. Run `node scripts/board.mjs` first to see the active task, ready tasks, and blockers.
3. Follow the command files in `.claude/commands/` (`start-day`, `next`, `new-task`, `end-day`).
4. Change tasks only through the `backlog` CLI (`backlog task edit ...`), never by hand-editing task files.
